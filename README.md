# 方塊日程 timeblock

用拖拉方塊規劃每一天的個人管理系統：專案待辦、每日時間軸、固定行程、月曆、週統整。

網頁：<https://janice880624.github.io/timeblock/>

## 資料存在哪裡？兩種方式選一種

| | Google 帳號登入 | 我自己的 Google 試算表 |
|---|---|---|
| 設定 | 不用設定，登入就能用 | 第一次要花約 5 分鐘 |
| 資料位置 | 網站的 Firebase 資料庫 | 你自己雲端硬碟裡的試算表 |
| 誰看得到 | 只有你（網站管理者在後台技術上看得到） | 只有你 |
| 速度 | 快 | 開啟時要等 1～3 秒，儲存會稍微延遲 |
| 可以直接看資料 | 否 | 可以，試算表裡有「待辦清單」「方塊紀錄」「固定行程」頁 |

## 使用自己的試算表（Google Apps Script）

1. 建立一份新的 Google 試算表，選「擴充功能」→「Apps Script」。
2. 把 [`gas/Code.gs`](gas/Code.gs) 的內容全部貼上，取代原本的內容，然後儲存。
3. 在上方的函式選單選 `setup`，按「執行」。
   第一次會要求授權：選自己的帳號 →「進階」→「前往（專案名稱）」→「允許」。
   執行完，試算表會多一個「設定」頁，裡面有你的**連線密碼**。
4. 右上角「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**

   按「部署」，複製「網頁應用程式網址」（`/exec` 結尾）。
5. 打開方塊日程網頁，選「使用我自己的 Google 試算表」，貼上網址和連線密碼，按「連線」。

如果原本已經用 Google 帳號登入、建過資料，在連線視窗勾選「把目前的資料一起複製到這個試算表」，就會把資料搬過去。

### 注意

- **「誰可以存取：所有人」**是讓網頁連得到你的試算表。真正的保護是連線密碼，不要把密碼和網址給別人。
- `data` 工作表是網頁讀寫的資料，**請不要手動修改**。其他工作表只是方便閱讀的副本，在那裡修改不會同步回網頁。
- 換電腦或換手機時，在新裝置上重新輸入一次網址和密碼即可。
- 之後如果更新了 `Code.gs`，要到「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」，網址不會變。

### 想讓別人更快上手（給分享的人）

只做上面的步驟 1～2，做好一份範本試算表。**不要在範本上執行 setup**，這樣每個人複製後都會產生自己的密碼。把試算表的分享網址最後的 `/edit…` 改成 `/copy` 傳給別人，對方打開就會複製一份，**連 Apps Script 一起複製**，只要從步驟 3 開始做。
