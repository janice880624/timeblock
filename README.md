# 方塊日程 timeblock

用拖拉方塊規劃每一天的個人管理系統：專案待辦、每日時間軸、固定行程、月曆、週統整。

網頁：<https://janice880624.github.io/timeblock/>

## 資料存在哪裡？

每個人的資料都存在**自己 Google 雲端硬碟裡的試算表**，透過自己部署的 Google Apps Script 讀寫，只有自己看得到。

想先試試看的話，登入畫面選「先試用看看」，資料只會存在那台裝置的瀏覽器，之後連接試算表時可以一起搬過去。

## 設定步驟（約 3 分鐘）

1. **複製範本**：打開 [範本試算表](https://docs.google.com/spreadsheets/d/19JEZJzrM6RGVGR918iubUGKpUoQCeix7lGUA5LwTd_s/copy)，按「建立副本」。
2. **初始設定**：在你的副本上方選單選「方塊日程」→「初始設定」。
   第一次會要求授權：選自己的帳號 →「進階」→「前往（專案名稱）」→「允許」。
   完成後會跳出你的**連線密碼**，「設定」工作表裡也找得到。
3. **部署**：「擴充功能」→「Apps Script」→ 右上角「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**

   按「部署」，複製「網頁應用程式網址」（`/exec` 結尾）。
4. **連接**：打開方塊日程網頁 →「連接我的 Google 試算表」，貼上網址和連線密碼，按「連線」。

### 注意

- **「誰可以存取：所有人」**是讓網頁連得到你的試算表。真正的保護是連線密碼，不要把密碼和網址給別人。忘記密碼可以從「方塊日程」→「顯示連線密碼」查看；外流了就選「重新產生連線密碼」。
- `data` 工作表是網頁讀寫的資料，**請不要手動修改**。「待辦清單」「方塊紀錄」「固定行程」只是方便閱讀的副本，在那裡修改不會同步回網頁。
- 換電腦或換手機時，在新裝置上重新輸入一次網址和密碼即可。
- 之後如果更新了 `Code.gs`，要到「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」，網址不會變。

## 資料安全

- **沒存到的修改會補送**：每次修改會先暫存在瀏覽器裡，確認寫進試算表後才清掉。如果在儲存前關掉頁面或斷線，下次打開時會自動補存。
- **多台裝置一起用**：每筆資料都有版本號。另一台裝置先改過的話，會把兩邊的修改逐筆合併（新增、修改、刪除都會保留），不會整份蓋掉。切回頁面時，也會自動載入其他裝置的變更。
- **刪除可以復原**：刪除方塊、待辦、專案或固定行程後，畫面下方會出現「復原」按鈕，7 秒內按下就能救回來。
- **每日自動備份**：執行「初始設定」時會建立每天凌晨 3 點的自動備份，把 `data` 複製成隱藏的「備份 日期」工作表，最多保留 10 份。也可以從選單「方塊日程」→「立即備份」手動備份，或用「從備份還原…」還原；還原前會先自動備份目前的資料。

- **一整年的資料也不會變慢**：資料按月存放（每月一列），開啟時只讀前後三個月，翻到其他月份才讀。完成超過 45 天的待辦會移到封存區（`archive-年份`），週統整和試算表的「待辦清單」仍查得到。
- **每日紀錄**：每日規劃上方可以自己填心情（五個表情＋一句話）、體力（1–5）、睡眠時間、運動時間與內容，週統整會統計，試算表的「每日紀錄」工作表也會列出來（需更新 `Code.gs`）。
- **閱讀用工作表每 10 分鐘更新一次**，不拖慢存檔；急著看的話，從選單選「立即更新閱讀用工作表」。

> 從舊版更新的人：換上新的 `Code.gs` 後，到「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」，再從選單執行一次「初始設定」（會多要求一次「時間觸發」的授權），每日備份和定時更新才會開始。網址和密碼都不會變。第一次用新版網頁打開時，會自動把舊的「每天一列」轉成「每月一列」，轉換前會先備份。

## 不想用範本？

建立一份新的 Google 試算表 →「擴充功能」→「Apps Script」，把 [`gas/Code.gs`](gas/Code.gs) 的內容全部貼上並儲存，重新整理試算表後，從步驟 2 開始做。

## 開發

```
index.html          畫面結構
css/app.css         樣式
js/config.js        舊版 Google 登入設定（只用來搬舊資料）
js/core.js          常數與純函式：日期、格式、三方合併、排程計算（沒有畫面相依）
js/store.js         儲存層：試算表／本機模式、暫存佇列、版本合併、每月資料
js/state.js         記憶體裡的資料、讀取、封存
js/todo.js          分頁切換、「專案」頁
js/day.js           每日規劃（排程、時間軸）
js/drag.js          拖曳（滑鼠＋觸控）
js/modals.js        編輯視窗、復原
js/week.js          週統整
js/master.js        待辦總覽
js/habit.js         固定行程總覽
js/month.js         月曆
js/boot.js          啟動、連接試算表
gas/Code.gs         Apps Script 後端（貼到自己的試算表）
tests/              自動測試
```

`js/` 裡的檔案是一般的 `<script>`，照 `index.html` 裡的順序載入，彼此共用最上層的變數。

```
npm test            # 前端純函式＋Code.gs 測試（Node 22）
npm run mock        # 本機模擬 Apps Script（http://127.0.0.1:8787），會直接執行 gas/Code.gs
```

`tests/gas-env.js` 在 Node 裡模擬試算表、PropertiesService、LockService 等，讓 `Code.gs` 不用部署就能測。每次推上 GitHub 會自動跑測試（`.github/workflows/test.yml`）。
